# Om Prakash Borse — Portfolio V2

Recruiter-focused React + Vite portfolio.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## V2 improvements
- Premium editorial-style responsive UI
- Dark/light theme switch
- Recruiter-oriented hero and CTA
- Resume button with supplied resume
- Project detail modal with GitHub/live links
- Certificate preview modal using supplied PDFs
- Internship certificate links
- Structured experience, skills and recognition sections
- SEO/social metadata
- Mobile navigation
- No backend or environment variables required
